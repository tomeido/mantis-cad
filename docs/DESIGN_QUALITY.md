# 설계 구조와 곡선 품질 도구

CATIA의 연관 파라메트릭 설계와 Alias의 형상 진단 흐름을 참고해,
기존 노드·슬라이더·Undo·서명 이력 안에서 사용할 수 있는 기능을 추가했습니다.
별도 작업 환경 전환, 외부 CAD 설치, 새 런타임 의존성 없이 네이티브와 웹에서 동작합니다.

## 모델과 주요 치수 탐색

상단 **Design**으로 왼쪽 패널을 열고 **Model** 탭을 선택합니다.

- **Design parameters**에서 숫자 슬라이더의 이름과 값을 편집합니다. 명령으로 만든
  반지름·높이·간격도 같은 목록에 나타나고 연결된 형상이 다시 계산됩니다.
- **Features**는 입력이 결과보다 먼저 나오도록 의존관계 순서로 표시합니다.
  이름·종류로 검색하고, 항목 선택 시 노드 에디터의 선택과 위치가 연결됩니다.
- 선택한 항목의 입력·후속 연결을 따라가며 모델 구조를 확인합니다.
  평가 오류를 항목에서 찾고 **Inputs** 탭에서 실제 입력·출력을 확인합니다.
- 미리보기 토글은 형상을 표시하거나 숨깁니다. 후속 연산의 입력은 유지됩니다.

치수·이름·미리보기 변경은 기존 GraphOp로 기록되어 Undo/Redo·저장·리플레이에
포함됩니다. 과거 블록을 보는 동안에는 탐색만 가능하며 편집은 잠깁니다.
공유 입력이 여러 결과에 쓰이는 그래프이므로 단일 부품 계층으로 강제하지 않습니다.

## 제브라 음영

3D 뷰포트 상단에서 **Zebra**를 선택하면 반사 줄무늬로 메시 표면을 살펴볼 수 있습니다.
카메라를 회전하면서 줄무늬가 급격히 꺾이거나 끊기는 부분을 확인하고, 줄무늬 밀도를
조정합니다. **Shaded**로 돌아오면 일반 음영으로 표시됩니다.
곡선·점·그리드는 계속 표시되며, 이 설정은 모델 정의를 바꾸지 않습니다.

제브라는 테셀레이션 메시와 정점 법선을 이용한 시각적 진단입니다.
거친 메시나 잘못된 법선의 영향을 받으며, 해석적 곡면의 G1/G2 또는 Class-A 품질을
인증하지 않습니다. 곡면 패치 정렬·곡면 간 연속성 해결 기능은 포함하지 않습니다.

## 곡률 빗살

1. `Circle 5` 또는 `Curve 0 0 0 3 4 0 6 0 0`으로 곡선을 만듭니다.
2. 해당 곡선 출력 노드를 선택하고 `CurvatureComb 32 1`을 실행합니다.
3. 빗살을 보고 **Inputs** 탭의 출력에서 곡률과 유효성 목록을 확인합니다.

`CurvatureComb [samples [scale]]`의 기본값은 32개·배율 1입니다.
샘플 수는 정수 2~2,048, 배율은 0 이상입니다. 빗살 길이는 곡률×배율이며,
곡률의 단위는 모델 길이 단위의 역수입니다. 반지름 5인 원의 곡률은 0.2입니다.
직선은 곡률이 0이므로 빗살 길이가 0입니다.

`curve_comb` 출력은 `comb`(곡선 목록), `curvature`(숫자 목록), `valid`(불리언 목록)입니다.
빗살 직선은 각각 두 끝점만 렌더링하여 불필요한 세분화를 줄입니다.
모서리·퇴화점 등 미분이 정의되지 않는 샘플은 `valid=false`로 표시하고 길이와 곡률을
0으로 채웁니다. 이때 0을 평탄하다는 뜻으로 해석하지 마세요. 균일한 매개변수 샘플이므로
짧은 구간의 품질을 확인하려면 샘플 수를 늘려야 합니다.

## 곡선 끝점 연결 검사

곡선 두 개를 Shift+클릭으로 선택한 후 다음 명령을 실행합니다.

```
CurveContinuity 0.001 0.5 0.001
```

첫 번째 곡선의 **끝**과 두 번째 곡선의 **시작**을 비교합니다. 순서는 노드 위치의
위→아래, 같은 높이에서는 왼쪽→오른쪽입니다. 필요하면 노드 위치를 바꾸거나
`Reverse`로 곡선 방향을 뒤집습니다.

인자는 거리 공차, 접선 각도 공차(도), 곡률 벡터 차이 공차입니다. 모두 0 이상입니다.
노드에서는 각각 `gap_tol`, `angle_tol`, `curvature_tol` 입력으로 표시됩니다.
각도는 최대 180도입니다. `CurveContinuity`만 실행하면 각각 0.001 모델 단위,
0.01 라디안(약 0.573도), 0.001 역모델 단위를 사용합니다.

**Inputs** 탭에서 다음 출력을 확인합니다.

| 출력 | 의미 |
|---|---|
| `gap` | 두 끝점 사이 거리 |
| `angle` | 접선 방향 차이, 라디안 |
| `curvature_delta` | 곡률 벡터 차이의 크기 |
| `g0` | 거리 공차 만족 |
| `g1` | G0와 접선 각도 공차 만족 |
| `g2` | G1과 곡률 벡터 공차 만족 |

연결되지 않은 곡선의 접선만 같다고 G1/G2를 통과시키지 않습니다.
퇴화한 끝점처럼 미분이 정의되지 않는 입력은 오류로 보고합니다.
이는 곡선의 끝점 검사이며 전체 곡선이나 곡면 경계를 검증하는 기능은 아닙니다.

## 편집 가능한 접선 블렌드

예를 들어 아래 명령으로 두 선을 각각 만든 후 두 출력 노드를 선택합니다.

```
Line 0 0 0 2 0 0
Line 4 1 0 6 1 0
BlendCurve 1
```

첫 번째 곡선 끝에서 두 번째 곡선 시작까지 접선 방향을 잇는 3차 곡선을 만듭니다.
곡선 선택 순서는 연결 검사와 같습니다. 인자는 접선 핸들 배율이며 기본값 1,
허용 범위는 0 초과 10 이하입니다. 각 핸들 길이는 끝점 간 거리×배율÷3입니다.
원본 곡선은 보존되고, 원본이나 배율이 바뀌면 블렌드가 다시 계산됩니다.
끝점이 일치하거나 유효한 접선이 없는 경우에는 생성하지 않습니다.

이 블렌드는 G1 접선 연결을 위한 도구입니다. G2 곡률 연결은 보장하지 않으며,
큰 배율에서는 곡선이 돌아가거나 자기 교차할 수 있습니다.

## 구현 기준

기존 서명·문서 포맷은 유지하고 `curve_comb`, `curve_continuity`, `blend_curve`
컴포넌트를 추가했습니다. 새 컴포넌트를 포함한 문서는 해당 컴포넌트를 지원하는
버전에서 평가해야 합니다. 진단 결과는 저장된 입력으로 재계산합니다.
